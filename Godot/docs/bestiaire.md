# Ambrelune — Bestiaire

> Bible du jeu, 3/4. Qui vit où. Voir [mecaniques.md](mecaniques.md) pour les règles
> (habitats, rencontres, capacités) et [lore.md](lore.md) pour le pourquoi : Hélène a rendu chaque
> espèce à l'endroit de l'île qui ressemblait à son monde d'origine.

## Familles et types

| Famille | Type | Exemples |
|---|---|---|
| Raptors | vent | Velociraptor, Deinonychus, Utahraptor, Microraptor |
| Petits théropodes | vent | Compsognathus, Troodon, Oviraptor |
| Grands théropodes | feu | Dilophosaurus, Allosaurus, Carnotaurus, T-Rex |
| Spinosauridés | eau | Baryonyx, Suchomimus, Spinosaurus |
| Cératopsiens | terre | Protoceratops, Tricératops, Styracosaurus |
| Cuirassés | pierre | Ankylosaurus, Stegosaurus, Pinacosaurus |
| Pachycéphalosaures | pierre | Pachycephalosaurus, Stygimoloch |
| Ornithopodes | nature | Parasaurolophus, Iguanodon, Edmontosaurus |
| Sauropodes | terre | Brachiosaurus, Argentinosaurus |
| Ptérosaures | vent | Dimorphodon, Pteranodon, Quetzalcoatlus |
| Reptiles marins | eau | Plesiosaurus, Mosasaurus, Ichthyosaurus |

**Rareté** : C commun · P peu commun · R rare · TR très rare · *unique* = personnage (les **Anciens**,
parents des trois œufs : on les rencontre, on ne les capture pas). **Moment** : jour, nuit, pleine lune, pluie…
**Capacité** : voir le tableau des capacités d'exploration dans [mecaniques.md](mecaniques.md).
Niveaux indicatifs, pour une progression douce.

## Port-Ambre — pas de dinos sauvages

- **Les trois œufs d'Hélène**, au Cabinet : Velociraptor (**Vif**), Ankylosaurus (**Bastion**),
  Parasaurolophus (**Écho**). On en choisit un ; Maïa reçoit celui qui a l'avantage, l'Ombre Noire
  vole le troisième.
- Des **Compsognathus** chapardeurs traînent sur les quais (on peut les nourrir, pas les combattre).

## Terre des Apex — niv. 50

- **Le Souverain** : l'Apex ancestral, espèce inconnue, unique. Combat final (à apaiser).
- **Post-game** : les géants endormis du cratère, qui se réveillent un à un après la fin :
  Giganotosaurus, Argentinosaurus, Therizinosaurus géant… Et les espèces ressuscitées grâce aux
  fossiles complets, dont le **Titanosaure d'Or**.

## Compte

~55 espèces capturables sur le parcours principal, plus les légendaires et les fossiles du
post-game, soit environ 60. Chaque espèce demande une planche de profil et une planche face/dos
(voir [direction-artistique.md](direction-artistique.md)) : à produire **par lots, région par
région**, juste avant de construire la région.

**Visuels faits** (planche de profil + planche face/dos, `assets/art/dinos/`, via `tools/process-art.mjs`) :
les 9 espèces des Plaines, et le lot Grotte des Échos + Forêt Jurassique : Anurognathus,
Dilophosaurus, Stegosaurus, Deinonychus, Pachycephalosaurus, Microraptor, Brachiosaurus (juvénile),
Allosaurus, Utahraptor (Alpha) et Griffe-Grise (l'Ancien). Ces derniers n'ont pas encore leur fiche
d'espèce (`data/species/`) : elle viendra avec la région. Prochains lots : Marais, Désert, Côte,
Monts, Cieux, Volcan, puis les légendaires.
